# Video 17.2 – The Role of ETL in Data Engineering

**Duration:** 05:24

---

# Summary

This video explains where ETL fits within the broader data engineering and data science ecosystem.

Dr. Sanchez presents the complete data pipeline lifecycle, showing how data moves from source applications through storage systems, ETL processes, analytics platforms, and finally to end users and applications.

A key takeaway is that ETL acts as the bridge between data storage and data consumption.

---

# Learning Objectives

Understand:

- The end-to-end data engineering pipeline
- The role of ETL within modern data platforms
- Data collection methods
- Data storage technologies
- Data processing and analytics platforms
- Data consumption tools
- Real-world ETL use cases
