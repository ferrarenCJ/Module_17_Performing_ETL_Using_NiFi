# Mini-Lesson 17.1 – NiFi: An Apache ETL Tool

---

# Overview

Apache NiFi is an open-source data pipeline and transformation platform designed to automate and manage the flow of data between systems.

NiFi provides a web-based user interface that allows data engineers to visually create, configure, monitor, and manage ETL pipelines.

Key capabilities include:

- Data Ingestion
- Data Transformation
- Data Routing
- Data Monitoring
- Workflow Automation

One of NiFi's biggest advantages is its ability to modify data flows dynamically while the system is running.
