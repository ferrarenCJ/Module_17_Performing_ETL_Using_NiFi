# Module 17: Glossary

## Controller
A controller records connections between processes and controls the allocation of threads used by all processes within a NiFi workflow.

---

## ConvertJSONToSQL Processor
A NiFi processor that works with the PutSQL processor to generate SQL statements used to insert, update, or modify data in a database.

---

## ConvertRecord Processor
A NiFi processor that converts CSV FlowFiles into JSON FlowFiles. It uses controller services to read data from the source format and write data to the target format.

---

## Event
An event represents a change to a FlowFile as it moves through a NiFi flow. These events are tracked within NiFi repositories.

---

## GetFile Processor
A NiFi processor that searches a specified directory for files and creates FlowFiles from the discovered data.

---

## Flow (NiFi)
A NiFi flow is the overall data movement process that occurs after processors are connected and running. Data can be inserted, updated, transformed, or deleted during the flow.

---

## FlowFile
A FlowFile is the fundamental data object in NiFi. It contains the actual data along with metadata, enabling the processing of CSV files, images, videos, audio, and other binary data.

---

## NiFi
Apache NiFi is a data pipeline and transformation platform developed by the Apache Software Foundation that facilitates the movement and processing of data between systems.

---

## NiFi Pipeline
A NiFi pipeline consists of processors and connectors that work together to perform ETL operations and data movement between systems or databases.

---

## Process Group
A Process Group is a collection of processors, connectors, and ports that organize and manage related data flows within NiFi.

---

## Processor
A processor is the primary building block in NiFi responsible for creating, receiving, sending, transforming, splitting, merging, routing, and processing FlowFiles.

---

## PutSQL Processor
A NiFi processor that executes SQL statements generated by ConvertJSONToSQL. It commonly performs INSERT operations to load data into a database and may use multiple threads to improve performance.

---

## Reader
A Reader is a NiFi controller service used to read data from a source format. An example is CSVReader, which reads CSV-formatted data.

---

## Retries
Retries occur when a processor attempts an operation again after a temporary failure, such as a database table lock preventing data insertion.

---

## Source
A software installation method that involves compiling and installing software directly from source code without using a package manager or hosting service.

---

## SplitText Processor
A NiFi processor that splits a text file into multiple FlowFiles, typically creating one FlowFile per line. This is commonly used to process individual records from CSV files.

---

## Writer
A Writer is a NiFi controller service used to write data into a target format. An example is JsonRecordSetWriter, which outputs data in JSON format.

---
